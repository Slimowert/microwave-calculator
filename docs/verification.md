# План и протокол испытаний

## Цель и методика

Проверить аналитические модели, ограничения ввода, прохождение всех расчётов через интерфейс и пригодность экспортированных файлов. Контрольные случаи воспроизводятся командой `python -m pytest -q` в корне проекта.

| Объект | Контрольный пример | Критерий |
|---|---|---|
| Микрополосковая линия | εr = 4, W/h = 2 | εэфф = 3,06694671 и Z = 51,03739018 Ом, по формулам Позара |
| Синтез линии | Z = 50 Ом, h = 0,8 мм, εr = 3,55 | Отклонение после обратного расчёта до 0,1% |
| Трансформатор | 50 → 100 Ом, 2,4 ГГц, εэфф = 4 | 70,71067812 Ом, 15,61419052 мм, КСВН = 1 на f₀ и модуль отражения 1/3 на 2f₀ |
| Т-делитель | r = 1, 2 и 1/2 | Согласование входа, заданное деление, баланс мощности и наличие связи между выходами |
| Уилкинсон | r = 1, 2 и 1/2 | Согласование всех портов, развязка, ожидаемое деление и равные фазы на f₀ |
| Частотный решатель | Все топологии и взаимно обратные отношения r | Взаимность, пассивность, перестановка выходов и работа на полуволновой частоте |
| Интерфейс | Все шесть режимов, редактирование исходных данных | Расчёт из формы, сброс устаревших результатов, сообщение о неверном вводе |
| Экспорт | JSON, CSV, PNG и недоступный путь | Читаемые файлы с ожидаемыми данными, сообщение при ошибке записи |

Для ненулевых аналитических эталонов применяется относительный допуск 10⁻⁶. Для нулевого отражения и связи, баланса мощности, взаимности и пассивности применяется абсолютный допуск 10⁻⁶ в безразмерных величинах. Для разности фаз на центральной частоте — 10⁻⁶ рад. Все сравнения относятся к идеализированным моделям.

## Результаты

Окружение проверки — Windows 10 x64, Python 3.13.7. В 29 автоматических проверках приложение, ядро и экспорт прошли сценарии из таблицы. Интерфейс проверялся через Qt в режиме отрисовки без видимого окна, включая запуск всех десяти режимов.

Дополнительные проверки подтверждают согласование, развязку и равное деление для 2, 3 и 8 выходов Уилкинсона, рассеяние половины мощности в резистивном делителе и совпадение частотных характеристик LC-фильтров с аналитическими характеристиками Баттерворта и Чебышёва. Для Чебышёва проверены чётный и нечётный порядки.

Для неравноплечего Уилкинсона при 2,4 ГГц, 50 Ом, r = 2, h = 0,8 мм и εr = 3,55 получены доли мощности 1/3 и 2/3. Ветви — около 102,99 и 51,49 Ом. Развязывающий резистор — около 106,07 Ом.

Расчёт этого варианта на 1001 точке занял около 0,010 с, на 10001 точке — около 0,085 с. Замер включает вычисление частотной сетки и S-параметров и сделан без построения графиков и экспорта.
