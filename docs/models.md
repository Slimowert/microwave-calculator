# Расчётные модели и контракты

Основной источник — David M. Pozar, *Microwave Engineering*, 4th ed., Wiley, 2012. Номера разделов и формул приведены по этому изданию.

## Микрополосковая линия

В формулах (3.195)–(3.196), §3.8, используется отношение u = W/h. Эффективная проницаемость равна (εr + 1)/2 + (εr − 1)/(2√(1 + 12/u)).

| Условие | Волновое сопротивление |
|---|---|
| u ≤ 1 | 60 ln(8/u + u/4) / √εэфф |
| u > 1 | 120π / [√εэфф · (u + 1,393 + 0,667 ln(u + 1,444))] |

Длина волны равна c/(f√εэфф). Численный синтез инвертирует ту же модель методом Брента отдельно на каждой ветви. Из кандидатов берётся ширина с минимальной ошибкой по сопротивлению. При расхождении более 0,1% синтез отклоняется. Это также обрабатывает небольшой разрыв приближения при u = 1.

Интервалы 0,01 ≤ u ≤ 100 и 1 ≤ εr ≤ 20 задают область поиска программы. Это программные границы, а не гарантия точности приближения на всём интервале. Модель квазистатическая, проводник имеет нулевую толщину, частотная дисперсия и потери не учитываются. Условие h ≤ λ₀/20 предлагается как ориентир для оценки применимости.

## Четвертьволновой трансформатор

По §2.3 и §5.4 при действительных положительных сопротивлениях Z₀ и R волновое сопротивление участка равно √(Z₀R), длина равна λ/4 на f₀. Для θ = πf/(2f₀) коэффициент отражения равен (R − Z₀)cos θ / [(R + Z₀)cos θ + 2j√(Z₀R)sin θ]. КСВН равен (1 + |Γ|)/(1 − |Γ|).

## Делители мощности

Порт 1 возбуждается на входе. Все внешние порты имеют одинаковое действительное Z₀. Для r = P₃/P₂ и k = √r:

| Топология | Ветвь к порту 2 | Ветвь к порту 3 | Развязывающий резистор |
|---|---|---|---|
| Т-делитель, §7.2 | Z₀√(1 + r) | Z₀√(1 + 1/r) | отсутствует |
| Уилкинсон, §7.3 | Z₀√2 | Z₀√2 | 2Z₀ |
| Уилкинсон с неравным делением, §7.3 | Z₀√(k(1 + r)) | Z₀√((1 + 1/r)/k) | Z₀(k + 1/k) |

У неравноплечего Уилкинсона внутренние нагрузки имеют сопротивления kZ₀ и Z₀/k. К ним подключаются выходные четвертьволновые участки √kZ₀ и Z₀/√k, соответственно. Резистор соединяет внутренние сечения. При r = 1 дополнительные участки опускаются, а плоскости отсчёта совпадают с равноплечим исполнением. Четвертьволновая длина каждого участка рассчитывается по его собственной эффективной проницаемости.

Частотный решатель формирует узловые уравнения токов с ABCD-связями каждого участка и граничными условиями на опорных сопротивлениях (§4.3–4.4). Три столбца возбуждения дают комплексную S-матрицу одновременно. Явное решение для токов участков позволяет обходиться без котангенсов и деления на sin θ при полуволновой длине. В схеме отсутствуют неоднородности, паразитные параметры, потери и дисперсия.

## Дополнительные делители

Резистивный делитель представлен звездой из трёх сопротивлений Z₀/3. При согласованных портах коэффициент передачи по амплитуде равен 1/2 на каждый выход. На каждом выходе получается четверть входной мощности, остальная половина рассеивается.

Для симметричного Уилкинсона на N выходов сопротивление каждой четвертьволновой ветви равно Z₀√N. Между каждым выходом и плавающим общим узлом включён резистор Z₀. Для N = 2 это эквивалентно одному резистору 2Z₀ между выходами. В режиме нескольких выходов размер матрицы S равен (N+1) × (N+1).

## Фильтры нижних частот

По §8.3–8.4 синтезируется LC-лестница с последовательными индуктивностями и поперечными конденсаторами. Нормированные коэффициенты g для Баттерворта и Чебышёва пересчитываются как L = Z₀g/(2πf₀) и C = g/(2πf₀Z₀). Для Чебышёва чётного порядка рассчитывается отличное от Z₀ сопротивление нагрузки. Матрица S относится к сопротивлениям источника и нагрузки, указанным в результате. Расчёт учитывает идеальные сосредоточенные элементы. Частота f₀ означает уровень −3,01 дБ у Баттерворта и границу пульсаций у Чебышёва.

## Программный интерфейс

- Функции `microstrip`, `transformer`, `divider` принимают частоту в Гц, размеры в метрах и сопротивления в омах. Некорректные значения вызывают `InputError`.
- Структура `Result` содержит исходные параметры, описание модели и итоги. Массив `scattering` имеет форму (число частот, число портов, число портов). Индексы Python начинаются с нуля. Центральная матрица вычисляется отдельно от частотной сетки.
- Частотные кривые описываются `Trace` с названием, единицей и массивом длины N. Уровень S-параметра равен 20 log₁₀|S|, нижний порог −100 дБ применяется только при построении графика.
- Описание единиц присутствует в именах полей JSON и заголовках CSV. Для NaN и бесконечностей в JSON используется null со статусом, в CSV — пустое поле с колонкой статуса. Комплексные S-параметры экспортируются действительной и мнимой частями.
