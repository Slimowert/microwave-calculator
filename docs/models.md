# Расчётные модели и контракты

Основной источник — David M. Pozar, *Microwave Engineering*, 4th ed., Wiley, 2012. Номера разделов и формул приведены по этому изданию.

## Микрополосковая линия

В формулах (3.195)–(3.196), §3.8, используется отношение u = W/h. Эффективная проницаемость равна (εr + 1)/2 + (εr − 1)/(2√(1 + 12/u)).

| Условие | Волновое сопротивление |
|---|---|
| u ≤ 1 | 60 ln(8/u + u/4) / √εэфф |
| u > 1 | 120π / [√εэфф · (u + 1,393 + 0,667 ln(u + 1,444))] |

Длина волны равна c/(f√εэфф). Численный синтез инвертирует ту же модель методом Брента отдельно на каждой ветви. Из кандидатов берётся ширина с минимальной ошибкой по сопротивлению. При расхождении более 0,1% синтез отклоняется. Это также обрабатывает небольшой разрыв приближения при u = 1.

Интервалы 0,01 ≤ u ≤ 100 и 1 ≤ εr ≤ 20 задают область поиска программы. Это программные границы, а не гарантия точности приближения на всём интервале. Модель квазистатическая, проводник имеет нулевую толщину, частотная дисперсия и потери не учитываются. Условие h ≤ λ₀/20 предлагается как ориентир для оценки применимости.

## Четвертьволновой трансформатор

По §2.3 и §5.4 при действительных положительных сопротивлениях Z₀ и R волновое сопротивление участка равно √(Z₀R), длина равна λ/4 на f₀. Для θ = πf/(2f₀) коэффициент отражения равен (R − Z₀)cos θ / [(R + Z₀)cos θ + 2j√(Z₀R)sin θ]. КСВН равен (1 + |Γ|)/(1 − |Γ|).

## Делители мощности

Порт 1 возбуждается на входе. Все внешние порты имеют одинаковое действительное Z₀. Для r = P₃/P₂ и k = √r:

| Топология | Ветвь к порту 2 | Ветвь к порту 3 | Развязывающий резистор |
|---|---|---|---|
| Т-делитель, §7.2 | Z₀√(1 + r) | Z₀√(1 + 1/r) | отсутствует |
| Уилкинсон, §7.3 | Z₀√2 | Z₀√2 | 2Z₀ |
| Уилкинсон с неравным делением, §7.3 | Z₀√(k(1 + r)) | Z₀√((1 + 1/r)/k) | Z₀(k + 1/k) |

У неравноплечего Уилкинсона внутренние нагрузки имеют сопротивления kZ₀ и Z₀/k. К ним подключаются выходные четвертьволновые участки √kZ₀ и Z₀/√k, соответственно. Резистор соединяет внутренние сечения. При r = 1 дополнительные участки опускаются, а плоскости отсчёта совпадают с равноплечим исполнением. Четвертьволновая длина каждого участка рассчитывается по его собственной эффективной проницаемости.

Частотный решатель формирует узловые уравнения токов с ABCD-связями каждого участка и граничными условиями на опорных сопротивлениях (§4.3–4.4). Столбцы возбуждения всех внешних портов дают комплексную S-матрицу одновременно. Явное решение для токов участков позволяет обходиться без котангенсов и деления на sin θ при полуволновой длине. В схеме отсутствуют неоднородности, паразитные параметры, потери линий и дисперсия; резистивные потери учитываются.

## Дополнительные делители

Резистивный делитель представлен звездой из трёх сопротивлений Z₀/3. При согласованных портах коэффициент передачи по амплитуде равен 1/2 на каждый выход. На каждом выходе получается четверть входной мощности, остальная половина рассеивается.

Для симметричного Уилкинсона на N выходов сопротивление каждой четвертьволновой ветви равно Z₀√N. Между каждым выходом и плавающим общим узлом включён резистор Z₀. Для N = 2 это эквивалентно одному резистору 2Z₀ между выходами. В режиме нескольких выходов размер матрицы S равен (N+1) × (N+1).

## Явное распределение мощности: 2–10 выходов

`distribution.distributed_divider` принимает число выходов N и N положительных процентов с суммой 100% (допуск округления 10⁻⁶ процентного пункта). Нули, отрицательные и нечисловые значения отклоняются. Порт 1 — вход, выходы — порты 2…N+1. Заданные доли pᵢ относятся к сумме выходных мощностей на f₀, а фактические мощности `|Sᵢ₁|²` — к падающей входной мощности. Реальная доля и целевая доля перечисляются отдельно в подробностях. Одна секция Т-делителя и Уилкинсона реализует заданные доли на f₀; частотные зависимости решаются по схеме, без подстановки целевых процентов в S-матрицу.

### Т-соединение

N четвертьволновых ветвей имеют сопротивления Zᵢ = Z₀/√pᵢ. Их входные проводимости при согласованных выходных нагрузках на f₀ суммируются в 1/Z₀. Вход согласован, мощность сохраняется, выходные порты взаимно связаны и в общем случае не согласованы.

### Обобщённый Уилкинсон

Использована схема с внутренними нагрузками Rᵢ = A/pᵢ, четвертьволновыми ветвями Zᵢ = √(Z₀A)/pᵢ, плавающей звездой из резисторов Rᵢ и выходными трансформаторами Zтᵢ = √(Z₀Rᵢ). Подход описан в [H.-R. Ahn, K. Lee, N.-H. Myung, General Design Equations of N-Way Arbitrary Power Dividers, IEEE MTT-S, 2004](https://koasas.kaist.ac.kr/bitstream/10203/21409/1/%5BMTT_2004%5DGeneral%20design%20equations%20of%20N-way%20arbitrary%20power%20dividers.pdf). Параметр A сначала выбирается как Z₀, умноженное на геометрическое среднее долей, затем при необходимости корректируется с учётом диапазона сопротивлений микрополосковых ветвей и трансформаторов. При равном делении A=Z₀/N, внутренние сопротивления равны Z₀ и выходные трансформаторы опускаются.

Для одной секции на f₀ согласованы все порты и развязаны все пары выходов. Двухвыходный случай совпадает с приведёнными выше формулами. Для нескольких секций подбираются общие нормированные Z и R: сопротивления линий каждого плеча масштабируются его Rᵢ, а резисторы каждой плавающей звезды — тем же Rᵢ. Оптимизируются общий режим с входной нормированной нагрузкой Z₀/A и нечётные режимы. Выходные доли на f₀ сохраняются; согласование многосекционной схемы является результатом численной оптимизации по полосе. Внешние трансформаторы при неравном делении остаются частью расчётной сети. Все участки имеют длину λg/4 на f₀, рассчитанную по своей εэфф.

### Резистивная схема

Сначала строится согласованная звезда из N+1 одинаковых резисторов R=Z₀(N−1)/(N+1). Её коэффициент передачи по амплитуде на каждый выход равен 1/N. На выходах с меньшей долей устанавливаются согласованные Т-аттенюаторы с амплитудной передачей aᵢ=√(pᵢ/pmax). Два последовательных резистора каждого аттенюатора равны Z₀(1−aᵢ)/(1+aᵢ), шунтирующий — 2Z₀aᵢ/(1−aᵢ²); при aᵢ=1 аттенюатор опускается. См. [Qucs, Attenuators](https://qucs.github.io/tech/node95.html).

Порты остаются согласованными, а суммарная доля переданной входной мощности равна η=1/(N²pmax); остаток рассеивается. При двух равных выходах сохраняется исходная модель из трёх резисторов Z₀/3 и мощностями 25% входной на каждом выходе. Выбор звезды с аттенюаторами обеспечивает положительные номиналы и любое положительное распределение; это одна конкретная реализация, без оптимизации её потерь.

### Отображение и экспорт

Схема строится по рассчитанным ветвям, трансформаторам, резисторам и шунтам, включая все выходы. На схеме Уилкинсона одноимённые узлы u в линейной и резистивной частях соединены электрически. Частотные графики содержат передачу на каждый выход и КСВ всех N+1 портов. Для индексов 10 и 11 имена записываются явно, например `S[11,1]`, чтобы не смешивать `S[1,11]` и `S[11,1]`. CSV содержит полную комплексную S-матрицу, а JSON — также входные проценты и описание топологии. Физическая разводка HFSS остаётся доступной для двухвыходных Т-делителя и односекционного Уилкинсона; для N>2 кнопка выключена.

## Фильтры нижних частот

По §8.3–8.4 синтезируется LC-лестница с последовательными индуктивностями и поперечными конденсаторами. Нормированные коэффициенты g для Баттерворта и Чебышёва пересчитываются как L = Z₀g/(2πf₀) и C = g/(2πf₀Z₀). Для Чебышёва чётного порядка рассчитывается отличное от Z₀ сопротивление нагрузки. Матрица S относится к сопротивлениям источника и нагрузки, указанным в результате. Расчёт учитывает идеальные сосредоточенные элементы. Частота f₀ означает уровень −3,01 дБ у Баттерворта и границу пульсаций у Чебышёва.

## Программный интерфейс

- Функции `microstrip`, `transformer`, `divider` принимают частоту в Гц, размеры в метрах и сопротивления в омах. Некорректные значения вызывают `InputError`.
- `distribution.distributed_divider` принимает также `outputs` (2–10), `percentages` (N процентов) и `stages` (1–8, только для Уилкинсона). Поле `Result.topology` описывает ветви, резистивные звёзды, трансформаторы и аттенюаторы рассчитанной схемы.
- Структура `Result` содержит исходные параметры, описание модели и итоги. Массив `scattering` имеет форму (число частот, число портов, число портов). Индексы Python начинаются с нуля. Центральная матрица вычисляется отдельно от частотной сетки.
- Частотные кривые описываются `Trace` с названием, единицей и массивом длины N. Уровень S-параметра равен 20 log₁₀|S|, нижний порог −100 дБ применяется только при построении графика.
- Описание единиц присутствует в именах полей JSON и заголовках CSV. Для NaN и бесконечностей в JSON используется null со статусом, в CSV — пустое поле с колонкой статуса. Комплексные S-параметры экспортируются действительной и мнимой частями.
